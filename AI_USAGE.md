# AI Improvement Record

## Original Development

I developed the original version of the Personal Budget Tracker myself by creating the menu system, writing the main functions, and implementing the core budgeting features. Before making the first required GitHub commit, I only used AI occasionally to ask questions about Python syntax, CSV files, and how certain functions should work. The original application was fully functional before I used AI to make improvements.


## AI Tools Used

- GitHub Copilot

## Improvements Requested

After creating a working version of the application, I used GitHub Copilot to request suggestions for improving the overall quality of the project. My requests focused on:

- Improving the organization and readability of the code.
- Making the menu and program output cleaner and easier to read.
- Adding clearer function docstrings and comments.
- Organizing and formatting the README file.
- Troubleshooting small coding issues and understanding why certain solutions worked.
## Changes Accepted

I accepted several suggestions that improved the presentation and readability of the application while keeping the original functionality the same.

- Improved the formatting of the main menu to make it more organized and user-friendly.
- Improved the output displayed after adding income and expense transactions by making confirmation messages clearer.
- Reformatted the transaction list and balance summary so the information is easier to read.
- Added clearer function docstrings and comments throughout the program.
- Improved the formatting and organization of the project documentation, including the README file.

After making each change, I tested the application in PyCharm to make sure every feature still worked correctly. I also reviewed each suggestion until I understood how it worked before including it in my final project.


## Changes Rejected or Revised

Some suggestions included adding extra features or making the application more complex than what was required for the project. I chose not to include those suggestions because I wanted to keep the application within the scope of IS 3020 and make sure I understood every part of the final submission. I also modified some formatting suggestions so they better matched my own coding style.

## What I Learned

Using GitHub Copilot helped me improve the overall quality of my project while strengthening my understanding of Python. I learned more about organizing code into clear functions, creating cleaner console output, writing better documentation, and making applications easier for users to navigate. Testing the suggested improvements and reviewing the changes helped me better understand how to improve both the readability and usability of a Python program.
