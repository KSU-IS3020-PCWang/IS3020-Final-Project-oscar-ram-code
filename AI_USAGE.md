# AI Improvement Record

## Original Development

I developed the original version of the Personal Budget Tracker myself by creating the menu system, writing the main functions, and implementing the basic budgeting features. Before making the first required GitHub commit, I only used AI to ask a few questions about Python syntax, CSV files, and how certain functions should work. The original application was able to run and perform its basic tasks before I used AI to improve it.

## AI Tools Used

- GitHub Copilot

## Improvements Requested

After creating a working version of the application, I used GitHub Copilot to help improve the project by requesting suggestions for:

- Improving the organization and readability of my code.
- Better input validation using `try/except`.
- Adding clearer function docstrings and comments.
- Organizing the README file.
- Troubleshooting small coding issues and understanding why certain solutions worked.

## Changes Accepted

I accepted several suggestions that improved the overall quality of my application while keeping my original design.

- Improved input validation by using `try/except` blocks to prevent the program from crashing when users entered invalid numbers.
- Added clearer function docstrings and comments to make the code easier to understand.
- Reorganized parts of the code so each function had a single, clear responsibility.
- Improved the formatting and organization of the project documentation.

After making each change, I tested the application in PyCharm to make sure everything still worked correctly. I also reviewed each suggestion until I understood how it worked before including it in my final project.

## Changes Rejected or Revised

Some suggestions added extra features or made the code more complex than what was required for the project. I chose not to include those suggestions because I wanted to keep the application within the scope of IS 3020 and make sure I fully understood every part of the final submission. I also modified some suggestions so they better matched my own coding style and the requirements of the assignment.

## What I Learned

Using GitHub Copilot helped me strengthen my understanding of Python rather than simply giving me answers. I learned more about organizing code into functions, validating user input with `try/except`, working with CSV files, writing better documentation, and improving the overall readability of my code. Testing the suggested improvements and reviewing them helped me better understand how the program works and made me more confident in my Python programming skills.
